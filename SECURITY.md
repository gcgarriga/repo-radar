# Security Policy

`repo-radar` is alpha; only `main` is supported.

To report a vulnerability, please use [GitHub's private vulnerability reporting](https://github.com/gcgarriga/repo-radar/security/advisories/new) on this repository, or email `gcgarriga@gmail.com` with `[repo-radar security]` in the subject. Please do not open a public issue for security reports.

Include a short description, repro steps or proof of concept, and the commit/tag you tested against. I aim to acknowledge within 7 days.
